# Sources / Validation Notes

## Architecture
- C4 Model official site: https://c4model.com/
- C4 describes system context, container, component and code views, with supporting dynamic/deployment diagrams.
- C4's own guidance recommends context/container diagrams for most teams and supplements them with workflow/data diagrams where appropriate.

## Security
- OWASP ASVS official project: https://owasp.org/projects/asvs
- OWASP Developer Guide ASVS: https://devguide.owasp.org/en/06-verification/01-guides/03-asvs/
- ASVS 5.0.0 is the current stable version referenced by the official OWASP project page at the time this documentation baseline was prepared.
- The project targets ASVS Level 2 as a practical baseline, but this documentation does not claim certification or compliance.

## External marketplace integration
The Shopee integration is intentionally documented as a verification gate. The exact current official Open Platform endpoints, permissions, event types, rate limits, sandbox and production approval process must be checked against the current official provider documentation before implementation.

## Research
Literature review and SINTA classification must be performed against the official/authoritative indexing sources and the final target journal's current author guidelines. Do not use an assumed SINTA rank or an old paper as proof of current classification.
