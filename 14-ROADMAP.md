# Roadmap

## Phase 0 — Research & feasibility
- Literature review.
- User/problem validation.
- Verify provider API capabilities and permissions.
- Define research variables.
- Freeze MVP scope.

Deliverable:
Approved research scope + integration feasibility matrix.

## MVP freeze rule
After Phase 0, new features require an explicit change request and must not silently expand the thesis scope.
